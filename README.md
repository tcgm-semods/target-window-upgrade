# Target Window Upgrade

A Star Empire mod. Draws the targeted ship's own sprite as a watermark in
the Target panel, and swaps the panel's right-click / Shift+right-click
(and V / Shift+V) actions.

See [`source/README.md`](source/README.md) for details.

## Install

Grab the latest `.semod` from [Releases](../../releases/latest) and drop
it into the Star Empire Mod Manager.
